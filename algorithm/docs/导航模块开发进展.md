## 模块架构

```
视觉模块输入（Target3D: x, y, 距离, 角度）
  ↓
MVP 比例控制器（mvp_controller.py）          ← 当前主力
  → 角度偏差 → 转向
  → 距离偏差 → 前进速度
  → 到达目标 → 停止
  → 防卡住：连续30步不动 → 随机扰动脱困
  → 慢速接近：距离<1m 时减速
  ↓
ROS 桥接（ros_bridge.py）
  → 发布 /cmd_vel (geometry_msgs/Twist)
  → 仅使用 linear.x（前进速度）和 angular.z（转向速度）
  ↓
电控组订阅 /cmd_vel → 差速计算 → 电机转速（电控组负责）
```

复杂场景路径规划（待联调）：
```
栅格地图（map_builder.py）
  ↓
A* 全局规划（global_planner.py）→ 全局路径点
  ↓
DWA 局部避障（local_planner.py）→ 速度指令
  ↓
输出给底盘
```

## 与电控组接口

- **Topic**：`/cmd_vel`
- **消息类型**：`geometry_msgs/Twist`
- **有效字段**：
  - `linear.x`：前进速度（m/s），正值向前
  - `angular.z`：转向速度（rad/s），正值左转
- **其他字段**：全部设为 0，不使用
- **差速换算**：电控组根据轮距、轮径将 (v, ω) 转为左右轮转速

## 控制策略说明

MVP 采用纯比例控制，状态机逻辑：

1. **搜索状态**：原地旋转寻找目标
2. **对准状态**：根据角度偏差转向，对准目标
3. **前进状态**：对准后直线前进，持续修正方向
4. **减速接近**：距离 < 1m 时线性减速
5. **到达停止**：进入抓取半径后停车
6. **防卡住**：连续30步位置不变 → 随机小角度扰动脱困
7. **切换目标**：捡完一个球后平滑过渡到下一个目标
