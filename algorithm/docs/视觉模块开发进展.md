# 视觉模块开发进展

## 当前状态

视觉模块核心算法已完成，可以从图像中识别乒乓球并输出其在车体坐标系下的三维位置。

- **目标检测模型**：YOLO11 Nano，单类（乒乓球），已用真实数据集训练完成
- **模型精度**：mAP50 = 91.7%，精确率 90.1%，召回率 88.8%
- **本地测试**：12 张真实场景图片全部检测成功，置信度 0.80~0.94
- **坐标解算**：像素坐标 → 相机坐标 → 车体坐标，完整链路已打通
- **输出格式**：标准 `Target3D` 结构，包含车体坐标(x, y, z)、距离、角度、置信度，导航模块可直接消费

## 模块架构

```
图像输入
  ↓
YOLO 检测器（yolo_detector.py）
  → 输出：检测框、中心点、类别、置信度
  ↓
坐标变换器（coordinate_transform.py）
  → 针孔相机模型 + 地面平面假设
  → 像素 → 相机坐标 → 车体坐标(x前, y左, z上)
  ↓
目标选择器（target_selector.py）
  → 策略：最近目标 / 最高置信度 / 指定类别
  → 从多个目标中选出一个导航目标
  ↓
输出给导航模块（Target3D 对象）
```

## 坐标系说明

- **车体坐标系**：车头前方为 X 正方向，左侧为 Y 正方向，上方为 Z 正方向
- **相机坐标系**：光轴前方为 Z，右方为 X，下方为 Y（OpenCV 标准）
- **图像坐标系**：左上角为原点，向右为 u，向下为 v

坐标变换公式基于针孔相机模型和地面平面假设（球在地面上，z=0），详细推导见代码注释。

## 待实车配合事项

以下工作需要等小车上的相机安装完成后才能进行，目前参数为占位值：

1. **相机标定**：用棋盘格标定板获取相机内参（焦距、主点、畸变系数），替换 `camera_config.yaml` 中的默认值
2. **外参测量**：测量相机安装高度和俯仰角，填入配置文件
3. **ROS 接入**：从摄像头 ROS topic 订阅图像，替换当前的 cv2 读图方式
4. **实车微调**：用小车摄像头在实际场地拍一批照片做 fine-tune，进一步提升精度
